이 컴퓨터를 c-monitor 대시보드 서버에 연결하는 명령입니다. 사용자가 준 인자: `$ARGUMENTS`

인자에 따라 아래 셋 중 하나를 그대로 따르세요.

## 가. 인자가 비어 있을 때 — 상태 확인

Bash 도구로 다음을 실행하고, 출력을 사용자에게 그대로 보여 준 뒤 끝냅니다.

```
node "${CLAUDE_PLUGIN_ROOT}/bin/connect.mjs" --status
```

## 나. 인자가 `--status` 또는 `--disconnect`일 때

Bash 도구로 다음을 실행하고, 출력을 사용자에게 그대로 보여 준 뒤 끝냅니다.

```
node "${CLAUDE_PLUGIN_ROOT}/bin/connect.mjs" $ARGUMENTS
```

## 다. 인자가 서버 주소일 때 — 연결 (반드시 두 단계로)

연결은 사용자가 브라우저에서 승인해야 끝납니다. Bash 도구는 명령이 끝나야 출력을 보여 주므로, **한 번에 실행하면 사용자가 승인 링크를 보지 못한 채 기다리게 됩니다.** 그래서 반드시 아래 두 단계로 나눠 실행합니다.

1. **요청** — Bash 도구로 다음을 실행합니다. 몇 초 안에 끝납니다.

   ```
   node "${CLAUDE_PLUGIN_ROOT}/bin/connect.mjs" $ARGUMENTS --start
   ```

   이 명령이 실패로 끝났으면(서버에 닿지 않음 등) 출력된 안내를 그대로 전하고 여기서 끝냅니다. 2·3단계로 넘어가지 마세요.

2. **링크와 코드를 사용자에게 보여 주기** — 다음 명령을 실행하기 **전에**, 1단계 출력의 승인 링크와 확인 코드를 사용자에게 눈에 띄게 보여 줍니다.

   - **답의 첫 줄에 승인 링크 전체 주소를 그대로 적습니다**(1단계 출력의 `● 승인 링크` 뒤 주소). "링크를 열고"처럼 주소 없이 링크를 가리키기만 하는 말은 쓰지 마세요.
   - 링크는 한 글자도 바꾸지 말고 누를 수 있는 형태로 한 줄에 따로 적습니다.
   - 확인 코드는 **굵게** 적습니다. 한 글자도 바꾸지 마세요.
   - 출력에 "브라우저를 열었습니다"가 있으면 브라우저가 자동으로 열렸다고 알리고, "아래 링크를 직접 열어 주세요"가 있으면 링크를 직접 열어야 한다고 알립니다. 출력에 적힌 대로만 말하세요.
   - 브라우저에서 구글로 로그인한 뒤 화면의 코드가 위 코드와 같은지 확인하고 승인하면 된다고 안내합니다.

3. **승인 기다리기** — 그런 다음 Bash 도구로 다음을 **제한시간 10분(timeout 600000)** 으로 실행합니다. 사용자가 승인할 때까지 기다리는 명령이므로 중간에 끊지 마세요.

   ```
   node "${CLAUDE_PLUGIN_ROOT}/bin/connect.mjs" --wait
   ```

   끝나면 출력을 고치거나 줄이지 말고 사용자에게 그대로 전합니다. 실패로 끝났으면(거부·만료 등) 출력된 안내를 전하고, 다시 시도하려면 같은 명령을 한 번 더 실행하면 된다고 알려 줍니다.

## 지킬 것

- 명령이 출력한 내용을 고치거나 줄이지 마세요.
- 문제가 생겨도 스스로 설정 파일을 고쳐서 해결하려 하지 마세요.
- `~/.c-monitor/config.json`과 `~/.c-monitor/pending.json`에는 토큰·기기 코드가 들어 있습니다. 읽거나 출력하지 마세요.
