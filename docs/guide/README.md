# C-Monitor 사용 설명서

C-Monitor는 여러 컴퓨터의 클로드코드 세션을 한 화면에서 보는 대시보드입니다. 각 컴퓨터에 플러그인을 설치해 서버에 연결하면, 그 컴퓨터의 세션 상태와 대화, 계정별 사용 한도가 대시보드에 실시간으로 나타납니다.

눌러 볼 수 있는 데모는 <https://korthomasjeong.github.io/c-monitor/> 에 있습니다. 실제 화면을 예시 데이터로 돌리는 데모이며 실제 서버와 연결되지 않습니다. 이 설명서의 스크린샷은 실제 웹 화면에 지어낸 예시 데이터를 넣어 찍은 것입니다.
