# C-Monitor 사용 설명서

C-Monitor는 여러 컴퓨터의 클로드코드 세션을 한 화면에서 보고, 답을 기다리는 세션에 웹에서 바로 답하는 대시보드입니다. 각 컴퓨터에 플러그인을 설치해 서버에 연결하면, 그 컴퓨터의 세션 상태와 대화, 계정별 사용 한도가 대시보드에 실시간으로 나타납니다. 텔레그램이나 브라우저 알림으로 소식을 받고, 승인·선택지·다음 지시를 웹이나 텔레그램에서 보낼 수 있습니다.

눌러 볼 수 있는 데모는 <https://korthomasjeong.github.io/c-monitor/> 에 있습니다. 실제 화면을 예시 데이터로 돌리는 데모이며 실제 서버와 연결되지 않습니다. 이 설명서의 스크린샷은 그 데모(지어낸 예시 데이터)로 찍었습니다.

이 설명서는 플러그인 0.3.1 기준입니다.

## 처음 쓰는 분

1. [시작하기](getting-started.md) — 가입 고지와 동의, 가입 신청과 승인, 플러그인 설치와 업데이트, `/c-monitor:connect`, 연결 승인·거부

## 화면

2. [대시보드](dashboard.md) — 카드 색과 깜박임 규칙, 카드에서 바로 답하기, 컴퓨터별 묶음, 공유받은 세션, 상태 필터, 기록 탭, 테마
3. [간단히 보기](deck-mode.md) — 타일만 보는 화면, 휴대폰 가로 화면
4. [세션 상세](session-detail.md) — 대화·도구 탭, 컨텍스트·비용, 100줄씩 불러오기, 대화 검색, 글 입력창, 답 기록 줄, 세션 지우기
5. [사용 한도](limits.md) — 계정별 5시간·주간 한도 카드, 색 기준, 별칭·숨기기
6. [설정](settings.md) — 내 컴퓨터(원격 답장 스위치·연결 해제), 클로드 계정, 알림, 표시 기준, 보관 기간, 계정
7. [관리자](admin.md) — 가입 승인, 사용자 미리 추가·권한·용량 한도·정지·탈퇴 복구, 남의 대시보드 읽기 전용 보기, 모든 컴퓨터, 텔레그램 봇, 저장 용량

## 기능

8. [원격 답장](remote-reply.md) — 웹에서 승인(허용·이 세션 동안 허용·거부)·선택지·글 보내기, 터미널 우선, 원격 제어로 열기, 컴퓨터별 스위치
9. [알림](notifications.md) — 텔레그램 연결과 버튼·답장으로 답하기, 웹 알림(아이폰은 홈 화면 추가), 알림 소리, 항목별·세션별 스위치, 관리자의 봇 토큰
10. [공유](sharing.md) — 링크 공유(만료), 사람 지정, 공개 링크 화면, 공유받은 세션
11. [계정](account.md) — 가입 고지와 동의, 저장 용량, 탈퇴와 탈퇴 취소

13. [직접 서버 올리기](self-hosting.md) — 도커 컴포즈, 환경변수, 배포 스크립트, 프록시 설정, 백그라운드 작업

15. [자주 묻는 질문](faq.md) — 대화가 저장되는 곳, 관리자가 볼 수 있는 것, 지우는 방법, 웹 답장과 알림
