      데모/

      이 데모가 하는 일

      저장소의 web/을 그대로 빌드한 화면입니다. 앞에 붙은 demo.js가 서버 API와 실시간 스트림을 흉내 냅니다.

      • 답변 기다림·작업 끝남·작업 중·연락 끊김·종료·한도 초과 세션이 고루 들어 있습니다.
      • 컴퓨터 4대, 클로드 계정 2개(한 계정은 5시간 한도 80% 넘음)를 씁니다.
      • 몇 초마다 상태가 바뀌고 대화가 늘어나는 것은 미리 짜 둔 대본입니다.
      • 저장·승인·연결 해제는 그 창 안에서만 반영되고, 새로 열면 처음으로 돌아갑니다.
      • 웹에서 답장 보내기·알림·공유는 아직 없는 기능이라 데모에도 없습니다.

      디자인 캔버스 원본

      처음 화면을 그린 디자인 캔버스 파일입니다. 캔버스 도구 전용 형식이라 일반 브라우저에서는 열리지 않아 저장소에만 보관합니다.
