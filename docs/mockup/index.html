      데모/

      이 데모가 하는 일

      저장소의 web/을 그대로 빌드한 화면입니다. 앞에 붙은 demo.js가 서버 API와 실시간 스트림을 흉내 냅니다.

      • 답변 기다림·작업 끝남·작업 중·연락 끊김·종료·한도 초과 세션이 고루 들어 있습니다.
      • 컴퓨터 4대, 클로드 계정 2개(한 계정은 5시간 한도 80% 넘음)를 씁니다. 공유받은 세션 2개와 오래전에 끝난 세션 2개(기록 탭)도 있습니다.
      • 몇 초마다 상태가 바뀌고 대화가 늘어나는 것은 미리 짜 둔 대본입니다.
      • 저장·승인·연결 해제는 그 창 안에서만 반영되고, 새로 열면 처음으로 돌아갑니다.
      • 승인·선택지·글로 답하면 대화에 이어지는 답과 "웹에서 … 답했습니다" 기록 줄이 붙습니다.
      • 텔레그램 봇(@c_monitor_demo_bot)과 공유 링크, 다른 사용자들도 모두 지어낸 값이고, 실제 텔레그램이나 알림으로 나가는 것은 없습니다.
